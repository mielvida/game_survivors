# 게임 기획서 (GDD) — 가칭 「에테르 원정대 (Aether Vanguard)」

> 판타지 세계관의 파티형 서바이버 액션 게임
> 레퍼런스: 탕탕특공대(Survivor.io), Vampire Survivors, 20 Minutes Till Dawn

문서 버전: v0.1 (초안) · 작성일: 2026-10-17

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 로그라이트 서바이버 액션 (자동 공격 + 이동 조작) |
| 세계관 | 하이 판타지 — 마력(에테르)이 오염되어 몬스터가 들끓는 대륙을 원정대가 정화해 나간다 |
| 플랫폼 | **모바일 우선**(Android/iOS, 세로 화면) · 이후 태블릿/PC 확장 (9장 '기기 대응' 참고) |
| 조작 | 가상 조이스틱 한 손 조작. 공격은 자동, 플레이어는 이동·스킬 선택에 집중 |
| 플레이 단위 | 스테이지 1판 = 약 5~8분, 10스테이지마다 보스 |
| 핵심 차별점 | ① 최대 3인 **파티** 전투 ② 캐릭터별 **장비** 육성 ③ 레벨업 시 **스탯 포인트** 직접 분배 |

### 1.1 핵심 재미 (Design Pillars)
1. **쏟아지는 적을 쓸어버리는 쾌감** — 수백 마리의 적, 화려한 스킬 이펙트.
2. **파티를 키우는 즐거움** — 혼자 시작해 동료를 모으고, 3인 조합 시너지를 찾는다.
3. **내 손으로 만드는 빌드** — 스탯 분배 + 장비 + 판 내 스킬 선택이 겹쳐지는 깊이.
4. **명확한 목표** — 10스테이지마다 등장하는 보스가 실력·육성의 관문 역할.

## 2. 게임 루프

### 2.1 판 내 루프 (In-Run, 5~8분)
```
이동/회피 → 자동 공격으로 적 처치 → 경험치 보석 획득
   → 런 레벨업 → 스킬 카드 3장 중 1장 선택 → 더 강해짐 → 더 강한 웨이브
   → (엘리트/보스 처치) → 스테이지 클리어 → 보상
```

### 2.2 메타 루프 (Out-Run, 성장)
```
스테이지 보상(골드·장비·캐릭터 EXP·재료)
   → 캐릭터 레벨업 → 스탯 포인트 분배
   → 장비 착용/강화
   → 동료 영입 · 파티 편성
   → 다음 스테이지 도전
```

### 2.3 두 종류의 "레벨" 정리
서바이버 장르의 재미(판마다 새로 성장)와 요청된 "레벨업 시 스탯 찍기"를 모두 살리기 위해 레벨을 두 층으로 나눈다.

| 구분 | 런 레벨 (In-Run Level) | 캐릭터 레벨 (Character Level) |
|---|---|---|
| 유지 | 스테이지 종료 시 초기화 | 영구 유지 |
| 획득 | 필드의 경험치 보석 | 스테이지 클리어 보상 EXP |
| 레벨업 보상 | 스킬 카드 선택 (3택 1) | **스탯 포인트 5점** (직접 분배) |
| 목적 | 판마다 다른 빌드의 재미 | 장기 육성·캐릭터 개성 |

> ✅ 확정 #1: 스탯은 **캐릭터 레벨업 시에만** 직접 분배한다. 런 레벨업은 스킬 선택 전용이다.

## 3. 캐릭터 & 파티 시스템

### 3.1 파티 규칙
- 처음에는 **주인공 1명**으로 시작.
- 스테이지 진행으로 동료를 영입해 **최대 3명**까지 동시 출전.
- 플레이어는 **리더 1명을 직접 이동**시키고, 나머지 동료는 AI로 리더를 따라다니며 자동 공격.
- 전투 중 **리더 교체 버튼**(쿨타임 10초)으로 조작 캐릭터를 바꿀 수 있다.
- 체력은 캐릭터별 개별 관리. 쓰러진 동료는 20초 후 체력 30%로 부활(리더가 근처에 있으면 부활 시간 단축).
- 리더가 쓰러지면 남은 동료가 자동으로 리더가 됨. **전원 쓰러지면 패배**.
- 경험치 보석은 파티 공유(누가 줍든 런 레벨은 파티 공통).

### 3.2 동료 영입 흐름 (안)
| 시점 | 내용 |
|---|---|
| 스테이지 1 | 주인공(기사) 단독 |
| 스테이지 5 클리어 | 두 번째 동료 영입 (스토리 이벤트, 3명 중 1명 선택) |
| 스테이지 10 보스 클리어 | 세 번째 슬롯 해금 |
| 이후 | 여관(Tavern)에서 추가 영웅 영입 — 재화/조각 수집 방식 |

### 3.3 직업(클래스) 초안
| 직업 | 역할 | 기본 무기 | 특징 |
|---|---|---|---|
| 기사 (주인공) | 탱커/근접 | 회전 검격 | 높은 HP·방어, 주변 적 넉백 |
| 궁수 | 원거리 딜러 | 관통 화살 | 높은 치명타, 사거리 |
| 마법사 | 광역 딜러 | 화염구 | 넓은 범위, 낮은 HP |
| 성직자 | 서포터 | 신성 오라 | 파티 회복·보호막 |
| 도적 | 근접 딜러 | 단검 투척 | 빠른 이동·회피 |
| 정령사 | 소환 | 정령 소환 | 소환수가 적을 어그로 |

- **파티 시너지**: 직업 조합에 따른 보너스 (예: 기사+성직자 = "성기사단": 방어 +10%, 궁수+도적 = "그림자 사냥꾼": 치명타 +8%).

## 4. 스탯 시스템

### 4.1 기본 스탯 (캐릭터 레벨업 시 5포인트 분배)
| 스탯 | 효과 (1포인트당) |
|---|---|
| 힘 (STR) | 물리 공격력 +2, 넉백 +0.5% |
| 민첩 (DEX) | 공격 속도 +0.6%, 치명타율 +0.2%, 이동속도 +0.2% |
| 지능 (INT) | 마법 공격력 +2, 스킬 쿨타임 -0.3% (최대 -40%) |
| 체력 (VIT) | 최대 HP +12, 방어력 +0.5 |
| 행운 (LUK) | 치명타 피해 +1%, 아이템 드롭률 +0.3%, 경험치 획득 +0.3% |

- 직업별 **기본 성장치**가 다름(예: 기사는 레벨업마다 VIT +2 자동 상승).
- **스탯 초기화**: 무료 1회, 이후 보석 소모.
- **추천 분배** 버튼 제공(초보자 배려).

### 4.2 파생 스탯 (전투 계산용)
공격력, 공격속도, 치명타율, 치명타 피해, 최대 HP, 방어력, HP 재생, 이동속도, 쿨타임 감소, 범위 증가, 투사체 수, 자석 범위(보석 흡수), 경험치 배율.

### 4.3 데미지 공식 (초안)
```
기본피해   = 스킬계수 × (물리공격력 or 마법공격력)
치명타     = 기본피해 × (1.5 + 치명타피해%)   [치명타율 판정 시]
최종피해   = 피해 × (100 / (100 + 적방어력)) × 속성상성 × 랜덤(0.95~1.05)
```

## 5. 장비 시스템

### 5.1 장비 슬롯 (캐릭터별 6칸)
| 슬롯 | 주 옵션 |
|---|---|
| 무기 | 공격력 (직업 전용 무기군: 검/활/지팡이/단검/성구/보주) |
| 투구 | HP |
| 갑옷 | 방어력 |
| 장갑 | 공격속도 / 치명타율 |
| 신발 | 이동속도 |
| 장신구 | 랜덤 특수 옵션 |

### 5.2 등급
| 등급 | 색상 | 부가 옵션 수 | 비고 |
|---|---|---|---|
| 일반 | 회색 | 0 | |
| 고급 | 초록 | 1 | |
| 희귀 | 파랑 | 2 | |
| 영웅 | 보라 | 3 | |
| 전설 | 주황 | 3 + 고유 효과 | 예: "화염구가 2회 분열" |
| 신화 | 빨강 | 4 + 고유 효과 | 보스 전용 드롭 |

### 5.3 성장 요소
- **강화**: 골드 + 강화석으로 +1 ~ +15. 주 옵션 수치 상승. (+10 이상은 실패 가능, 장비 파괴 없음)
- **합성**: 같은 등급 장비 3개 → 상위 등급 1개.
- **세트 효과**: 같은 세트 2/4개 착용 시 보너스 (예: "용기사 세트").
- **분해**: 불필요 장비 → 강화석.

## 6. 판 내 스킬 시스템 (런 레벨업)

- 런 레벨은 파티 공통이지만, **스킬은 캐릭터별로 따로 고르고 따로 보유**한다.
- 런 레벨업 시 **현재 조작 중인 리더가 아닌, 카드를 받을 캐릭터를 먼저 선택**한 뒤 그 캐릭터의 스킬 카드 3장 중 1장을 고른다.
  - 연출: 화면에 파티원 초상화 3개 → 탭 → 카드 3장 표시. (선택 시간 제한 없음, 게임은 일시정지)
  - 편의 옵션: "자동 분배" 토글 ON이면 가장 스킬이 적은 캐릭터에게 우선 지급.
- 캐릭터당 **액티브 스킬 최대 4개 + 패시브 스킬 최대 4개**. 3인 파티 합계 액티브 12개 / 패시브 12개.
- 스킬은 Lv.1 ~ Lv.5. 액티브 Lv.5 + 같은 캐릭터의 대응 패시브 보유 시 **진화**(예: 화염구 + 마력의 서 → 메테오).
- 카드 풀: 공용 스킬 + 해당 캐릭터 직업 전용 스킬. 직업 전용 스킬이 등장 확률 우대.
- 리롤 1회 무료(광고 시청 시 +1회, 선택 사항).
- 파티 전용 카드(2명 이상일 때): "연계 공격 — 동료가 리더의 표적을 함께 공격" 등. 카드를 받은 캐릭터가 효과의 주체.

> ✅ 확정 #2: 스킬은 캐릭터별로 따로 선택한다.

## 7. 스테이지 구성

### 7.1 챕터 구조
- **1 챕터 = 10 스테이지**, 챕터마다 테마 맵과 보스가 다르다.
- 스테이지 1~9: 일반 스테이지 (5분 생존 또는 목표 처치 수 달성)
- 스테이지 5: 중간 보스(엘리트) 등장
- **스테이지 10, 20, 30…: 보스 스테이지** (보스 아레나, 제한시간 내 보스 처치)

| 챕터 | 스테이지 | 테마 | 보스 |
|---|---|---|---|
| 1 | 1~10 | 저주받은 숲 | 고대 트렌트 "썩은뿌리" |
| 2 | 11~20 | 망자의 묘지 | 리치 "모르그라스" |
| 3 | 21~30 | 화염 협곡 | 화염 비룡 "이그니스" |
| 4 | 31~40 | 얼어붙은 왕성 | 서리 여왕 "엘사리아" |
| 5 | 41~50 | 심연의 탑 | 타락한 대마법사 "아즈라엘" |

### 7.2 일반 스테이지 흐름 (5분 기준)
| 시간 | 이벤트 |
|---|---|
| 0:00~1:00 | 약한 몬스터 소규모 웨이브 |
| 1:00~2:30 | 몬스터 종류·수 증가 |
| 2:30 | 엘리트 몬스터 1마리 (보물상자 드롭) |
| 2:30~4:00 | 포위형 웨이브(원형으로 둘러싸기) |
| 4:00~5:00 | 대규모 러시 |
| 5:00 | 클리어 → 보상 |

### 7.3 보스 스테이지
- 1:30 동안 일반 웨이브로 준비 → 보스 등장 시 **아레나 벽**이 생겨 이동 범위 제한.
- 보스는 **2~3 페이즈** 패턴 (HP 70% / 30%에서 패턴 변화).
- 위험 범위를 **바닥 경고 표시(Telegraph)**로 예고 → 회피 플레이 강조.
- 처치 보상: 신화/전설 장비 확정 드롭 상자, 대량 골드, 챕터 해금.

### 7.4 스테이지 평가
- ★1: 클리어 / ★2: HP 50% 이상 유지 / ★3: 파티원 전원 생존
- 별 보상 누적으로 추가 보상 상자.

## 9. 경제 & 보상 / 수익 모델

### 9.1 재화
| 재화 | 획득처 | 용도 |
|---|---|---|
| 골드 | 스테이지 보상, 몬스터 | 장비 강화, 스탯 초기화 일부 |
| 강화석 | 분해, 보상 | 장비 강화 |
| 보석 | 업적, 보스, 별 보상 | 영웅 영입, 스탯 초기화, 부활 |
| 영웅 조각 | 보스, 이벤트 | 영웅 영입/승급 |

### 9.2 수익 모델 방침 (미확정 — 열어두는 설계)
- 현재는 수익 모델을 **확정하지 않는다**. 다만 나중에 붙일 때 구조를 갈아엎지 않도록 아래 원칙을 지킨다.
- 추가한다면 **보상형 광고(Rewarded Ad, 유저가 선택해서 시청)** 중심으로 한정한다. 강제 전면광고는 쓰지 않는다.
- 스태미나 시스템은 **넣지 않는 것을 기본**으로 한다(광고 의존도를 높이는 구조이므로). 필요해지면 그때 추가.
- 광고 연결 후보 지점 (모두 **선택 사항**, 안 봐도 진행 가능):
  | 지점 | 보상 |
  |---|---|
  | 런 도중 사망 시 | 1회 부활 |
  | 스테이지 클리어 결과 화면 | 보상 2배 |
  | 레벨업 카드 리롤 | 리롤 +1회 |
  | 로비 일일 상자 | 강화석/골드 |
- 설계 규칙: 광고 보상은 **편의/가속**만 주고, 광고를 보지 않아도 진행·보스 클리어가 가능하도록 밸런스를 맞춘다.
- 기술적으로는 `AdService` 인터페이스 뒤에 숨기고, 초기 빌드는 광고 없이(더미 구현이 즉시 보상 지급) 출시 가능하게 한다. (TECH_DESIGN 참고)

## 10. 아트 디렉션 (고퀄리티 목표)

### 10.1 스타일
- **2.5D 쿼터뷰 / 반실사 핸드페인팅 판타지** — 탕탕특공대보다 한 단계 높은 디테일.
- 캐릭터: 3~4등신 SD 비율, 실루엣이 직업별로 명확히 구분되도록.
- 컬러: 챕터별 고유 팔레트(숲=청록/보라, 묘지=회청/녹광, 협곡=주황/검정 …).
- 이펙트: 수백 마리 사이에서도 **아군 스킬 / 적 공격 / 위험 경고**가 색과 형태로 즉시 구분되어야 함
  (아군=밝은 금/청색, 적 투사체=붉은/보라 계열, 경고=빨간 바닥 링).

### 10.2 에셋 사양 (기준)
| 에셋 | 방식 | 해상도/사양 |
|---|---|---|
| 영웅 | Spine 2D 스켈레탈 애니메이션 (또는 3D → 프리렌더) | 원화 1024px, 인게임 약 128px 높이 |
| 일반 몬스터 | 스프라이트 시트 (8방향 대신 좌우 반전 2방향) | 프레임당 128×128, 걷기 8 / 피격 3 / 사망 6프레임 |
| 보스 | Spine + 셰이더 이펙트 | 인게임 약 384~512px |
| 배경 | 타일맵 + 장식 오브젝트 레이어 | 타일 128px, 챕터당 약 60종 |
| UI | 판타지 테마 프레임 (금속·양피지 질감) | 1080×1920 기준 9-slice |
| 장비 아이콘 | 등급별 테두리 + 아이콘 | 256×256 |

### 10.3 제작 파이프라인
1. 컨셉 아트(키 비주얼, 캐릭터 시트) — AI 이미지 생성 툴로 시안 대량 제작 → 아티스트가 리터칭·통일.
2. 확정 원화 → 파츠 분리 → Spine 리깅/애니메이션.
3. 스프라이트 아틀라스로 패킹 (드로우콜 최소화).
4. 포스트 프로세싱: Bloom, 컬러 그레이딩, 2D 라이트.

### 10.4 그래픽 방식 비교 (확정 #4: A+B 하이브리드)

"그래픽 방식"은 **캐릭터와 배경을 어떤 기술/스타일로 그려서 움직이게 할지**를 뜻한다. 같은 판타지 게임이라도 방식에 따라 제작비·성능·분위기가 크게 달라진다.

| | A. 2D 핸드페인팅 + 스켈레탈(Spine) | B. 2D 프레임 애니메이션(스프라이트 시트) | C. 3D 로우폴리/스타일라이즈드 쿼터뷰 |
|---|---|---|---|
| 한 줄 설명 | 일러스트를 파츠로 쪼개 뼈대로 움직임 | 한 동작을 그림 여러 장으로 그려 재생 | 3D 모델을 만들어 위에서 내려다보는 시점으로 렌더 |
| 느낌/비슷한 게임 | 일러스트 느낌이 강함 (Hades처럼 그린 듯한 화면, 모바일 RPG 영웅들) | 도트·카툰 느낌 (Vampire Survivors, 브로타토) | 입체감과 조명 (탕탕특공대, 3D 서바이버류) |
| 퀄리티 | 일러스트 그대로의 고퀄 | 장면당 프레임 수만큼 퀄리티가 비례 | 모델링·텍스처·조명에 의존 |
| 애니메이션 | 부드럽고 제작이 빠름 (뼈대 재사용) | 동작이 늘면 그려야 할 그림이 급증 | 리깅 후 모션 재사용 가능 |
| 대량의 적 | 중간 (적에는 B 혼용 권장) | **가볍고 유리** | 인스턴싱·LOD 필요, 상대적으로 무거움 |
| 모바일 성능 | 좋음 | 매우 좋음 | 중간~좋음 (최적화 필요) |
| 캐릭터 커스터마이징 | 장비 외형 교체 쉬움 (파츠 교체) | 장비마다 전 프레임을 다시 그려야 해서 어려움 | 장비 외형 교체 쉬움 (모델 교체) |
| 제작 난이도/비용 | 중 (일러스트레이터 + Spine 담당) | 높음 (그림 양) | 높음 (3D 아티스트) |
| AI 이미지 생성 활용 | 컨셉·원화 제작에 유리 | 프레임 간 일관성 확보가 어려움 | 컨셉 참고용으로만 |

**이 프로젝트 권장안: 하이브리드 (A + B)**
- 영웅/보스 → **A (Spine)**: 고퀄 일러스트 + 장비 착용 시 외형 변경(요청하신 장비 시스템에 가장 잘 맞음).
- 일반 몬스터(수백 마리) → **B (스프라이트 시트)**: 성능 확보.
- 배경 → 핸드페인팅 타일맵.
- 이유: "게임 이미지는 퀄리티 좋게"라는 목표와 "화면에 적이 수백 마리"라는 장르 특성을 동시에 만족하는 조합.
- 마음에 드는 느낌의 레퍼런스 게임/이미지를 알려주시면 방식을 확정하고 해당 스타일의 키 비주얼 시안 제작 방향을 잡을 수 있다.

### 10.5 기기 대응 (모바일 우선)

우선 **모바일 세로 화면**을 기준으로 개발하되, 처음부터 기기에 따라 자동 대응되도록 설계한다.

| 항목 | 방침 |
|---|---|
| 기준 해상도 | 1080×1920 (9:16) 기준 UI, 앵커 기반 배치 |
| 화면 비율 | 16:9 ~ 21:9(긴 화면)·태블릿(4:3) 대응. 가로가 넓어지면 전투 시야를 넓히고 UI는 가장자리 정렬 |
| 노치/펀치홀 | Safe Area 적용 |
| 성능 등급 | 기기 사양에 따라 **자동 품질 설정**(상/중/하): 최대 적 수, 이펙트 수, 포스트프로세싱, 그림자, 프레임(60/30) |
| 저사양 | 이펙트 간소화 + 동시 적 수 상한 하향(예: 150) + 30fps 옵션 |
| 배터리 | 절전 모드(30fps) 옵션 |
| 입력 | 모바일: 가상 조이스틱(고정/플로팅 선택) · 이후 PC: WASD/게임패드 · 태블릿: 조이스틱 크기 조절 |
| PC 확장(후순위) | 가로 화면 레이아웃 + 키보드/패드 지원. 전투 로직은 입력과 분리해 두어 확장 비용을 줄임 |
