# M0 프로토타입 실행 가이드

Unity 6 프로젝트의 첫 프로토타입입니다. 목표는 **핵심 재미 검증**입니다. 그래픽은 기본 도형으로 대체했습니다.

## 실행 방법
1. Unity Hub에서 **Unity 6 (6000.0.x LTS)** 를 설치합니다. 버전이 다르면 Hub에서 설치된 6000.x 버전으로 열면 됩니다.
2. Hub에서 `Add project from disk`로 이 저장소 루트(`game_survivors`)를 엽니다. 처음 열 때 패키지 가져오기 때문에 몇 분 걸립니다.
3. 열리면 `File > New Scene`으로 빈 씬(Basic)을 만들고 **Play**를 누릅니다. 씬을 직접 꾸미지 않아도 `Bootstrap`이 실행 중에 전부 만듭니다.
4. 처음 열고 나면 Unity가 `.meta` 파일을 생성합니다. 이 파일들은 커밋해야 합니다.

## 조작
| 기기 | 조작 |
|---|---|
| 모바일/마우스 | 화면을 누른 채 드래그 (가상 조이스틱이 누른 위치에 생김) |
| PC | WASD 또는 방향키 |
| 공격 | 자동 |

## 구현된 것
- 고정 각도 3D 쿼터뷰 카메라, 무한처럼 보이는 바닥
- 영웅 이동, 체력, 피격
- 적 3종 (슬라임, 해골, 엘리트 브루트) 시간에 따라 늘어나는 웨이브, 최대 200마리
- 적 일괄 업데이트 + 공간 해시 기반 겹침 방지
- 경험치 보석과 자석 흡수, 런 레벨업
- 레벨업 시 스킬 카드 3장 선택 (액티브 3종: 마법 화살 / 정령의 칼날 / 신성한 파동, 패시브 5종)
- 5분 생존 시 클리어, 사망 시 패배, 다시 하기
- EditMode 테스트 (경험치 곡선, 공간 해시, 스킬 카드 추첨)

## 아직 없는 것 (다음 마일스톤)
- 파티 3인, 동료 AI, 리더 교체 (M1)
- 캐릭터 레벨/스탯 분배, 장비, 세이브 (M2)
- 보스, 스테이지 선택, 챕터 (M3)
- 실제 3D 에셋, GPU 인스턴싱, 기기 등급별 품질 설정
- 정식 UI (지금은 IMGUI 임시 화면)

## 알아둘 점
- 이 코드는 Unity가 없는 환경에서 작성되어 **아직 한 번도 컴파일/실행해 보지 않았습니다.** 처음 열었을 때 오류가 나면 Console 내용을 알려주세요.
- 머티리얼은 `Universal Render Pipeline/Lit`을 먼저 찾고 없으면 `Standard`를 씁니다. 빌드(APK)에서는 사용하는 셰이더가 포함되도록 `Project Settings > Graphics > Always Included Shaders`에 추가해야 할 수 있습니다.
- 한글은 OS 폰트로 표시됩니다. 일부 기기에서 깨지면 정식 UI 단계에서 폰트를 포함합니다.
